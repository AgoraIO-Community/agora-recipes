## Instruction completeness and ambiguity

- **Python: instructions located successfully, with an extra documentation hop.** The catalog Markdown contains an Agora CLI initialization command and detailed integration contracts, but not a complete standalone installation sequence. Its “Related Progressive Disclosure Docs” names `L1/01_setup.md` as code text rather than a clickable link. The explicit bootstrap link leads to a clickable setup document. That [setup document](https://github.com/AgoraIO-Conversational-AI/agent-quickstart-python/blob/main/docs/ai/L1/01_setup.md) provides Python ≥3.10, bun, pip/venv, Agora credential requirements, installation, environment variables, startup and verification commands. This was enough to locate instructions without guessing a URL or executing commands.
- **RTC: instructions located successfully, with limited inline detail.** The [catalog guide](http://localhost:3418/recipes/live-video-react-app/index.md) contains prerequisites, credential names, run expectations and RTC checks, but uses generic “install dependencies / start development server” wording without exact commands or a precise config filename. Following its [repository link](https://github.com/AgoraIO-Community/live-video-react-app-dev) exposes a short README with the actual install/start commands. No claim is made that credential configuration is fully specified or the app runs successfully.
- **Desktop Pet: setup text is directly usable for locating the workflow.** The [candidate guide](http://localhost:3418/recipes/desktop-pet/index.md) and [Chinese author guide](https://raw.githubusercontent.com/SyunWong/desktop-pet/main/README.zh-CN.md) include prerequisites, clone/setup/launch commands, environment variable names, voice configuration, browser preview and verification steps. Instructions were read, not executed; author statements about tested platforms or providers were not independently validated.
- **Origin ambiguity:** literal index navigation leaves the local candidate for production. The production Markdown responses lacked the candidate's top-level guide-language/status fields; the Desktop Pet production response also lacked the candidate's explicit alternate-author-guide metadata. Production 200 responses therefore do not prove that the candidate changes are deployed. The documented same-path origin mapping isolates the candidate evaluation.

All three requested discovery tasks succeeded through the entry point and its documentation links. This measures task discoverability in one controlled agent navigation test. It does **not** measure search-engine ranking, traffic, recommendation frequency, or adoption/citation by external AI tools.
